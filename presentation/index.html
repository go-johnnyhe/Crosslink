CROSSLINK

Real-time multiplayer Tic-Tac-Toe

Johnny He and Yiwen Hu · CS5700 Final Project

Introduction

  • Two players, two browsers, one Tic-Tac-Toe board
  • A Next.js server holds the single copy of the game state
  • Demonstrates real-time client-server synchronization

System Features

Gameplay

  • Turn-based moves, synced in real time
  • One shared board state
  • Win, loss, and draw tracking

Networking

  • Matchmaking and private room codes
  • In-game chat
  • Connection activity log

System Analysis & Design

The server validates every move against the player's identity, the current turn, and the board state before applying it.

Implementation & Methodology

Stack

  • Next.js route handlers for the API
  • React client, no external state library
  • One in-memory store for all rooms

Synchronization

  • Actions sent by POST, state pushed over Server-Sent Events
  • Server re-validates every move on arrival
  • One open stream per player, no polling

Transport Choice

Our first version polled that payload every 850 ms whether or not anything changed. Server-Sent Events send nothing until state changes, and measured delivery is 39 ms. We evaluated WebSocket and rejected it: traffic is almost entirely server-to-client, and EventSource reconnects on its own.

Testing & User Manual

How we verified

  • Two browsers side by side, full games played
  • Out-of-turn and taken-square moves rejected
  • Join, move, chat, win, draw, and rematch

Run it

  • npm ci && npm run dev
  • Open two browser windows
  • Find a match, or share a room code

Improvements & Future Work

  • Persistent storage across server restarts
  • WebSockets, if the game ever needs a busy upward channel
  • Spectator mode and voice chat
  • Player accounts with saved stats

Conclusion

Crosslink implements every required feature: matchmaking, synchronized moves, chat, win/loss/draw tracking, and a connection activity log. Game state lives in memory and resets when the server restarts, a deliberate simplification for this project's scope.
